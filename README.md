# 德州扑克 SNG 锦标赛（单机版）

9 人单桌 Sit & Go 德州扑克锦标赛：你 + 8 个风格化 AI，完整真实比赛规则，内置实时分析辅助工具（胜率、对手范围推断、底池赔率/EV、翻前范围表、逐街复盘）。

纯前端单机，无服务器；`npm run release` 产出单文件 HTML，双击即玩。桌面与手机竖屏均已适配（≤760px 时 HUD 变为底部抽屉 + 悬浮胜率按钮，行动条为全宽大按钮）。

## 命令

```bash
npm install
npm run dev      # 开发（http://localhost:5173）
npm test         # vitest 全量测试（引擎规则/评牌器/equity 基准/AI 一致性/fuzz 不变量）
npm run build    # tsc 类型检查 + vite 单文件构建
npm run release  # 构建并输出 release/德州扑克SNG.html（file:// 双击可玩）
```

## 玩法

- 9 人各 1500 筹码，买入 100，前三名分奖 450/270/180
- 盲注每 9 手升一级（后期含 ante），打到只剩 1 人
- 快捷键：`F` 弃牌 / `C` 过牌·跟注 / `R` 加注（滑条定额）/ `A` 全下
- 顶栏可切换：加速、风格标签、隐藏辅助（纯净模式）
- 进度在手与手之间自动存档（localStorage），大厅可继续或复盘

## 辅助工具

| 工具 | 说明 |
|------|------|
| 实时胜率 | Web Worker 蒙特卡洛（增量收敛，上限 40 万次）；河牌/窄范围自动切精确枚举（标"精确"） |
| 对手范围 | 13x13 热力矩阵：按每个 AI 的风格策略函数对其行动线做贝叶斯收窄，与 AI 实际决策共用同一 policy，推断天然一致 |
| 赔率 & EV | 底池赔率、跟注所需胜率、跟注/弃牌 EV 对比条 |
| 翻前范围表 | 按位置的标准开牌/3bet/防守范围（紧凶基准），当前手牌高亮 |
| 复盘 | 每手事件溯源记录，逐街回放 + 上帝视角 + 当时胜率快照 + 范围推断随游标重算 |
| 赛后分析 | 比赛结束自动生成（固定规则、确定性）：VPIP/PFR/WTSD 等统计 + 负赔率跟注/错失价值/短码漏推/松紧被动诊断，复盘界面也可随时查看 |

## AI 阵容

大厅可选两套阵容：

- **传奇桌**（默认）：扑克史知名选手的打法致敬版，各自独立参数——艾维🦁（全能）、毒王德万🔥（超凶）、赫尔穆斯👑（极紧）、丹牛🎯（小球）、布朗森🤠（老派凶）、Isildur⚡（疯狂）、陈强尼🐉（稳凶）、昂格尔☄️（天才凶）
- **风格桌**：基础五风格——紧凶🦈 / 松凶🐺 / 岩石🗿 / 跟注站🐮 / 疯鱼🐙

每个 AI 有翻前范围宽度、进攻性、诈唬频率、弃牌倾向等参数；短码（≤10bb）自动切 push/fold 近似 Nash 表；决策 = 策略分布 + 实时 equity 有界精修 + 种子化采样（同一种子完全可复现）。范围推断面板能直接读出每个人的倾向差异。

## 架构

```
src/core      纯 TS 牌局引擎（发牌/下注状态机/边池/摊牌/锦标赛层），事件溯源
src/analysis  范围(1326组合加权)/equity(MC+精确枚举)/贝叶斯推断/强度分桶/EV
src/ai        风格参数/翻前表(Chen公式百分位)/push-fold/策略函数π/决策
src/workers   equity worker（?worker&inline，兼容单文件构建）
src/store     gameController(主循环)/viewModel(事件→视图)/replay/storage
src/ui        React 组件（牌桌/行动条/HUD/范围矩阵/复盘/大厅）
tests         61+ 测试：评牌器对拍/规则剧本/equity 基准/AI 统计/fuzz 不变量
```

分层铁律：`ai → analysis → core` 单向依赖，均不含 DOM；UI 只经 store 消费引擎。引擎无时间概念，动画=事件流回放。所有随机数来自种子化 mulberry32，复盘确定性重算。
